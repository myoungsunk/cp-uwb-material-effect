# Issue / Debug Tracks

This folder separates two document roles:

- `problem` files:
  - define the issue, risk, scope, and acceptance target
- `debug` files:
  - record the actual debugging path, evidence, decisions, and outputs

Use this folder when a paper-facing issue needs a clean audit trail that is
separate from the normal stage reports.
