# Patch CP Stage System

This folder is the active working area for the CP patch-stage pipeline.

## Structure

- `code`
  - CP patch-stage extraction code
- `csv`
  - Stage-local copies of the current CP simulation CSVs
- `results`
  - CP patch-stage figures

## Scope

- `Gamma_X`
- first-order corrected `Gamma_C`
- patch-stage derived `R_TE` / `R_TM` proxies

## Non-Scope

- ideal plane-wave excitation
- intrinsic material-only TE/TM truth
